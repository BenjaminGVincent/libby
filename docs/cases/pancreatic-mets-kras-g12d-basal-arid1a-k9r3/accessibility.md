### 1. daraxonrasib (RMC-6236), pan-RAS(ON) inhibitor <small><code>daraxonrasib, RMC-6236</code></small> { #access-1 }

**Access status:** <span class="fit-badge fit-partial">Clinical trial</span> <span class="fit-badge fit-weak">Expanded access program</span> &nbsp; **Modality:** small_molecule &nbsp; **Verified:** 2026-06-06


The realistic path right now is a front-line trial: RASolute 303 (NCT07491445) takes treatment-naive metastatic PDAC and accepts the KRAS G12D under its RAS-mutant arm, with RMC-GI-102 (NCT06445062) as a backup that adds combination cohorts. The one thing worth nailing down before screening is a tissue NGS G12D result to back up the ctDNA call.

</dl>


**Next steps**

1. Call the Revolution Medicines study line (1-844-2-REVMED) or email medinfo@revmed.com to find the nearest RASolute 303 (NCT07491445) site with an open first-line slot

3. If no RASolute 303 site is reachable, ask the same line about RMC-GI-102 (NCT06445062) G12D subprotocols
4. Keep the daraxonrasib EAP (NCT07573215) on file as the off-trial route for later, once he has had a line of metastatic chemotherapy
