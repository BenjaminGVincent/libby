## Conventions

- Case URLs use a kebab-case clinical-descriptor slug + 4-character random
  suffix.
- Each case page is `<meta name="robots" content="noindex">` so search engines
  do not index it.
- Cases marked `private: true` in `profile.json` are not published; they
  remain local-only.
